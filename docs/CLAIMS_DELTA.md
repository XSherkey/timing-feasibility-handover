## 3. 论文里必须出现的四段"自我限制"

1. **常数基线**（A8）：标称物理下手调常数 94.0 > ALMOND 93.6。贡献必须落在
   "约束从哪来、怎么注入、能否复用、能否跟着物理走"，不是"我们的策略更好"。
2. **探测精度**（A14/A21）：阈值在 14–16 s 不可辨识；PCS 不能声称逐 seed 正确，
   只能声称平均跟随 + 标称 0 损失 + 逐 seed 失败率 2/5。
3. **门的两处缺陷**（A9/A10）：2-episode 估计噪声、用早期策略估计导致与部署价值相关性弱。
4. **单意图消融无效**（E1/E9 的 `no_memory`/`no_counterfactual`）：这两个组件的价值只在多意图协议（A7）与"门会拒"协议（A17）里体现。

## 4. 现在可以写的三个"卖点"（都有对照）

1. **机制**：可行性 vs 选择质量两因子分解，盾只修前者；天花板由其他失效类决定（A16 三物理一致）。
2. **注入**：同一知识，盾 93.6±0.7 / 最优惩罚 λ=8 84.4±6.8 / 无 71.8±12.6；且惩罚知识对漂移最脆弱（−29 pp）。
3. **审计**：门能拦住会损失 20–43 pp 的候选，且不误伤好候选（+0.4 pp）；代价是 2 个 episode 的回放。
